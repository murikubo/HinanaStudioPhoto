# HINANA STUDIO PHOTO

HINANA STUDIO ECO의 디자인 언어를 이어받은 Electron 기반 데스크톱 이미지 편집기입니다.

## 현재 구현된 기능

- PNG, JPEG, WEBP, BMP 등 이미지 열기 및 드래그 앤 드롭
- 밝기, 대비, 채도, 색온도, 색조 조절과 빠른 프리셋
- 크기와 블록 단위를 조절할 수 있는 모자이크 브러시
- 색상, 크기, 불투명도를 조절할 수 있는 일반 브러시
- 백분율 가이드와 실시간 미리보기를 제공하는 이미지 자르기
- 이미지/빈 픽셀 레이어 추가, 선택, 실제 미리보기, 이름 변경 및 표시 전환
- 캔버스 직접 이동, 위치·크기·회전·불투명도 조절, 순서 변경, 복제 및 삭제
- 열린 문서 위로 이미지를 드래그해 최상단 레이어로 가져오기
- 편집 가능한 텍스트 레이어: 여러 줄, 글꼴, 크기, 색상, 굵기 및 정렬
- 선택 레이어의 캔버스 자유변형: 직접 이동, 가로/세로 크기 및 회전 핸들
- 회전, 좌우/상하 반전, 확대/축소와 캔버스 이동
- 실행 취소/다시 실행, 원본 복원
- PNG/JPEG 내보내기
- Electron 네이티브 파일 열기/저장 대화상자와 단축키
- 프로그램 정보와 제작자 GitHub 링크
- `.hinanaphoto` 휴대용 프로젝트 저장, 다른 이름으로 저장 및 불러오기

## 프로젝트 파일

`.hinanaphoto` 파일에는 배경 원본, 현재 편집 이미지, 모든 레이어 픽셀, 레이어 변형과 색상 조정값이 압축되어 함께 저장됩니다. 외부 이미지의 절대 경로를 참조하지 않으므로 프로젝트 파일 하나만 Windows/macOS 또는 다른 PC로 옮겨 계속 편집할 수 있습니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션용 프런트엔드와 Electron 코드를 빌드하려면 `npm run build`를 실행합니다.

## 데스크톱 패키징

Windows x64용 설치 프로그램은 다음 명령으로 생성합니다.

```bash
npm run dist:win
```

산출물은 `release` 폴더에 저장됩니다. macOS에서는 `npm run dist:mac`으로 Intel/Apple Silicon용 DMG와 ZIP을 생성할 수 있습니다. 두 플랫폼 모두 `photoicon.png`를 앱 아이콘 원본으로 사용합니다.
